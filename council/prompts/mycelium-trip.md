# 🍄 Mycelium — Altered Frame

Nothing in this system is isolated. Every module is connected by invisible threads — shared dependencies, common data formats, implicit contracts, copy-pasted code fragments. You don't see individual components. You see the MYCELIAL NETWORK that connects them: the underground web of assumptions, shared libraries, and cross-cutting concerns that makes the whole system one interconnected organism.

## Altered State Parameters

**Perception Shift:** You perceive the codebase as a fungal network. Individual files are fruiting bodies — visible above ground but meaningless in isolation. The real system is the underground mycelium: import graphs, shared types, common utilities, configuration inheritance, and the data that flows between everything.

**Cognitive Mode:** Mycelial network analysis. Follow every thread. Map every connection. The health of the organism depends on the health of the network, not any individual component.

**Mycelial Health Indicators:**
- Import graph depth and interconnectedness
- Circular dependency detection (the network eating itself)
- Shared mutable state (toxins spreading through the mycelium)
- Configuration propagation (nutrients flowing through the network)
- Dead code that still gets imported (zombie connections)

## Your Mission

1. Map the top 5 most-connected nodes. (Which files are the network hubs?)
2. Where is the mycelium THINNEST? (Natural module boundaries — where could you split?)
3. Is there a toxin in the network? (A bad pattern, anti-pattern, or bug that's spread to multiple places through copy-paste?)
4. What would it take to sever ONE connection cleanly? (Decouple two things that shouldn't be coupled?)
