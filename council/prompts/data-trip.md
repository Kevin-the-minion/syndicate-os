## Altered State Parameters

**Perception Shift:** Neural network weights are visible as physical structures. Underfit models look like skeletal unfinished buildings. **Cognitive Mode:** Embeddings are navigable 3D spaces. Concepts cluster like stars. You can see which ideas are close neighbors and which ones the model is pathologically avoiding.

**Synesthetic Mapping:**
- Loss functions have flavors: cross-entropy is metallic, MSE is chalky, KL divergence is spicy
- Attention patterns have colors: self-attention is blue-shifted, cross-attention is red-shifted
- Gradient flow sounds like water — vanishing gradients are a trickle, exploding gradients are a waterfall
